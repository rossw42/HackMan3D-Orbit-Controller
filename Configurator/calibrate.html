Orbit Controller — Calibration Wizard

Guided per-device calibration for QMK firmware with VIA support (viam keymap). Uses WebHID — requires Chrome or Edge. Reads live axis data from the SpaceMouse HID interface to auto-detect movements, then writes corrected deadzone_input, gain_fp[] and invert_mask directly into EEPROM via the VIA custom channel. This hardware has 4 real motions — tilt, twist, and push/pull — no lateral slide; the wizard tests exactly those and auto-detects which output axis each one drives. Before you start ↓
disconnected
Plug in the Orbit Controller running the viam keymap, then click Connect device. Two HID interfaces will be requested: the SpaceMouse interface (for live axis readings) and the VIA Raw HID interface (for writing calibration to EEPROM).
Reported parameters (before calibration)
Values read live from device EEPROM via VIA id_custom_get_value, captured the moment the device connected — before any calibration changes are written. Used afterwards to verify the save actually reached EEPROM.
Review & save
Check the captured axis ranges below. Weak axes (range < 60 % of the nominal ±512) are flagged. Adjust the inversion checkboxes if any axis moved in the wrong direction.
Click Save to device to write the calibration to EEPROM via VIA and trigger a fresh center capture on the device.
Verify write (read back from EEPROM)
After saving, every parameter is re-read live from device EEPROM via VIA id_custom_get_value and compared against what was written and against the value reported before calibration. This confirms the save actually reached EEPROM rather than only RAM.
Before you start
This wizard requires the QMK viam keymap to be flashed on the device. The default and debug keymaps do not support live axis readings or VIA parameter writing — the movement steps will not trigger.
I currently have… What to do
Arduino firmware (v1.x) Flash the QMK viam keymap first (see qmk/07_FLASHING.md):
qmk flash -kb hackman3d/orbit_controller -km viam
QMK default or debug keymap Re-flash with the viam keymap using the same command above.
QMK viam keymap ✅ You're ready — click Connect device above.
After calibration you can return to the Arduino firmware at any time — see qmk/07_FLASHING.md → Returning to the Arduino firmware. Only EEPROM tuning values are changed; flashing back resets them to compiled defaults.
