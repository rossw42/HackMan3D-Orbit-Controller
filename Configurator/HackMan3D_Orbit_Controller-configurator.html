Dead zones ▶
DEADZONE_INPUT—
Removes electrical noise after reading joysticks. Increase if controller moves by itself; decrease if it needs too much force to react. Range: 30–70, default 40.
DEADZONE_OUTPUT—
Removes tiny movement values before sending to the computer. Increase if camera drifts after releasing knob; decrease if fine movements feel imprecise. Range: 25–80, default 45.
Smoothing & calibration ▶
SMOOTH_DIVISOR—
Higher = smoother but slower. Lower = faster but less filtered. Range: 3–8, default 5.
CENTER_SAMPLES—
Readings used during startup calibration. More = more stable center but longer startup. Range: 50–200, default 100.
CALIBRATION_MIN NEW—
Lowest acceptable analog center value at startup. If a joystick's resting value falls below this, the calibration-error LED flash fires. Default: 300.
CALIBRATION_MAX NEW—
Highest acceptable analog center value at startup. Values outside [CALIBRATION_MIN, CALIBRATION_MAX] trigger the 6-flash startup error. Default: 750.
Speed & response curve ▶
MAX_SPEED_SCALE—
Global speed cap. Decrease if all axes feel too fast; increase if too slow. Range: 0.50–1.00, default 0.70.
RESPONSE_CURVE—
How progressively the controller reacts near center. Higher = softer start; lower = more direct. Range: 1.0–2.2, default 1.6.
DEFAULT_SPEED_MODE—
Which speed mode the controller starts in. Default: 1 (normal).
Translation sensitivity ▶
GAIN_TX Left / Right—
Range: 1.0–3.0, default 1.3.
GAIN_TY Forward / Backward—
Range: 1.0–3.0, default 1.3.
GAIN_TZ Up / Down—
Range: 1.0–3.0, default 2.3.
Rotation sensitivity ▶
GAIN_RX Rotate X—
Range: 1.2–3.0, default 1.8.
GAIN_RY Rotate Y—
Range: 1.2–3.0, default 1.8.
GAIN_RZ Twist Z—
Range: 1.2–3.0, default 2.0.
Axis behavior ▶
ROTATION_PRIORITY—
Lower = rotation gets more priority over translation. Increase if translation cancels too easily. Range: 0.45–1.00, default 0.65.
ROTATION_PRIORITY_THRESHOLD NEW—
Minimum combined rotation strength before rotation priority can cancel translation. Higher = priority kicks in less often. Default: 80.
ENABLE_DOMINANT_AXIS_FILTER
Off
When on, only the strongest movement axis is sent. Useful if diagonal movements are too frequent. Default: off.
Z-axis gesture detection NEW ▶
Z_PUSHPULL_THRESHOLD_MULT—
Multiplier on DEADZONE_INPUT required before an up/down push-pull gesture is detected. Higher = harder to trigger accidentally. Default: 2.
Z_ROTATION_THRESHOLD_MULT—
Multiplier on DEADZONE_INPUT required before a twist (Z rotation) gesture is detected. Default: 3.
Z_ROTATION_DIVISOR—
Divides the raw twist signal before it becomes RZ output. Higher = gentler twist response. Default: 2.
Speed mode profiles ▶
Each mode has its own speed scale and response curve. Mode 0 = slow, 1 = normal, 2 = fast.
Speed mode button shortcut ▶
MODE_SWITCH_BUTTON_COUNT—
How many buttons must be held to switch speed mode. Set to 0 to disable the shortcut.
MODE_SWITCH_SUPPRESS_BUTTONS
Off
When on, the shortcut combo is not sent to the computer as normal button presses. Default: on.
MODE_SWITCH_CHORD_WINDOW_MS—
Time allowed to complete the speed-mode combo. Increase if CAD app receives one button before the full combo; decrease if held single buttons feel delayed. Range: 150–400, default 250.
MODE_SWITCH_DEBOUNCE_MS—
Debounce after switching speed mode. Increase if one press changes mode more than once. Range: 300–700, default 500.
Slicer mouse mode ▶
ENABLE_SLICER_MOUSE_MODE
Off
Enable slicer mouse mode support. Default: on.
DEFAULT_SLICER_MOUSE_MODE
Off
Start in slicer mouse mode instead of CAD mode. Default: off.
ENABLE_SLICER_KEYBOARD_SHORTCUTS
Off
Enable keyboard shortcuts in slicer mode. Default: on.
SLICER_MOUSE_MOVE_DIVISOR—
Controls drag speed. Increase if view moves too fast; decrease if too slow. Default: 120.
SLICER_MOUSE_WHEEL_THRESHOLD—
Minimum movement before zoom activates. Increase if zoom starts too easily. Default: 90.
SLICER_MOUSE_WHEEL_FULL_SCALE—
Movement magnitude that reaches maximum zoom speed. Default: 700.
SLICER_MOUSE_MAX_MOVE—
Maximum cursor step per report while dragging/panning. Default: 12.
SLICER_MOUSE_MAX_WHEEL—
Maximum wheel step per report while zooming. Default: 1.
SLICER_MOUSE_WHEEL_MIN_INTERVAL_MS—
Fastest zoom repeat rate. Lower = faster zoom. Default: 45.
SLICER_MOUSE_WHEEL_MAX_INTERVAL_MS—
Slowest zoom repeat rate. Higher = slower zoom. Default: 125.
SLICER_MOUSE_AUTO_DRAG
Off
Automatically hold mouse button while dragging in slicer mode. Default: on.
SLICER_BUTTON_LONG_PRESS_MS—
How long to hold a button for the long-press action in slicer mode. Default: 650 ms.
SLICER_MODE_HOLD_MS NEW—
How long the CAD/slicer toggle combo must be held before the mode actually switches. Default: 250 ms.
SLICER_MODE_DEBOUNCE_MS NEW—
Minimum time between two CAD/slicer mode toggles. Default: 500 ms.
Button debounce NEW ▶
BUTTON_DEBOUNCE_MS—
How long a button reading must stay stable before it's accepted. Prevents mechanical switch bounce from causing spurious mode changes or double presses. Default: 10 ms.
LED feedback NEW ▶
LED_BLINK_ON_MS—
Duration the TX LED stays lit during each speed-mode blink. Default: 80 ms.
LED_BLINK_OFF_MS—
Duration the TX LED stays off between speed-mode blinks. Default: 120 ms.
RX_LED_HOLD_MS—
How long the RX LED stays solid after toggling slicer mouse mode. Default: 500 ms.
Serial debug output ▶
DEBUG_SERIAL
Off
Enable serial output for debugging. Keep off during normal use. Default: off.
DEBUG_SERIAL_INTERVAL_MS—
How often to print debug data. Higher = less output. Default: 100 ms.
